# Dự án thực hành CodeGym

**CodeGym** là hệ thống đào tạo lập trình thực chiến hàng đầu tại Việt Nam, tiên phong áp dụng mô hình Coding Bootcamp giúp học viên nhanh chóng làm chủ kỹ năng nghề nghiệp để đáp ứng nhu cầu của doanh nghiệp.

Repository này được tạo ra nhằm mục đích lưu trữ mã nguồn, bài tập và các dự án thực hành cá nhân của tôi trong suốt quá trình tham gia khóa học tại CodeGym.
